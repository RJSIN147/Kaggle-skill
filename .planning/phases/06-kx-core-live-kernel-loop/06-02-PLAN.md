## Phase Goal

**As a** Kaggle competitor, **I want to** go from an empty folder to a recorded experiment through one `kx` CLI that runs my idea on a Kaggle script kernel by default, **so that** the core loop (idea, kernel run, machine-checked score, verdict, ledger, strategy) works live on the v2 foundations.

**This slice:** the user runs `kx init` in an empty folder and, in one step with no prompts, gets a git-backed v2 workspace plus a live-validated, masked Kaggle credential (ROADMAP success criterion 1).

<objective>
Deliver `kx init`: workspace scaffold (ported from v1 init_workspace.py minus every consent/egress/.env/pyproject
path) and live credential validation through an in-process, import-guarded, deadline-bounded Kaggle adapter.

Purpose: CORE-02 (setup + live credential validation in one step, masked, never echoed, no consent prompts) and
the CORE-01 envelope for the first real subcommand. Establishes the KaggleAdapter core and the workspace helpers
every later plan uses.

Output: `src/kx/{credentials,kaggle_adapter,workspace,leak_scan}.py`, `src/kx/commands/init.py`, three workspace
templates, the `kx_ws` test fixture, unit tests, and a LIVE init test run against the user's real credential.

Assumption surfaced to the user: **A5** — no v1 workspace is migrated; `kx init` refuses a folder whose
control/config.json has workspace_version 1 and tells the user to start a fresh workspace.
Discretion choices recorded: control JSON defaults become code (`default_config()`/`default_state()`) instead of
config.json.tmpl/state.json.tmpl, because v1 `_load_config_template` overwrote keys after json.loads anyway and it
keeps this plan within budget; v1 `pre-commit.tmpl` (an unused alternative shim) is not ported — the direct copy of
leak_scan.py is the only wiring kx uses; v1 `run_kaggle` subprocess runner is not ported — no Phase 6 command shells
out to the kaggle CLI (the SDK covers init/sync/run).
</objective>
