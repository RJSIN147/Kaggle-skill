Envelope (src/kx/envelope.py) — RESEARCH Pattern 1:
- `STATUSES = ("ok", "running", "needs_user", "invalid", "error")`
- `NEXT_KINDS = ("run", "edit", "ask_user", "done")`
- `make(command: str, status: str, *, summary: str = "", data: dict | None = None, warnings: list[str] | None = None, errors: list[str] | None = None, next_action: dict) -> dict`
  returns keys in this exact order: kx, command, status, summary, data, warnings, errors, next_action.
  `kx` = `kx.__version__`. Raises ValueError on an unknown status or next_action kind (programming error).
- `next_run(then: str, instruction: str | None = None) -> dict` -> {"kind": "run", "then": then[, "instruction"]}
- `next_edit(instruction: str, then: str) -> dict`
- `next_ask_user(instruction: str, then: str | None = None) -> dict`
- `next_done(instruction: str | None = None) -> dict`
- `exit_code(env: dict) -> int` -> 0 iff env["status"] in ("ok", "running"), else 1
- `LAST_ERROR_REL = "control/raw/last-error.txt"`
- `dump_last_error(ws: Path, text: str) -> Path` — port of scripts/kaggle_gateway.py 229-264 incl. its `_append_line_if_absent` (gitignore line BEFORE writing)
- `internal_error(command: str, exc: BaseException, ws: Path | None) -> dict` — status "error", errors == [f"internal_error:{type(exc).__name__}"]; traceback written via dump_last_error ONLY when `ws / "control"` is a directory; exception message text never enters the envelope.

Command-module contract (src/kx/commands/<name>.py; cli.py discovers them, later plans add them):
- `NAME: str` (subcommand), `HELP: str` (one line), `NEEDS_ADAPTER: bool`
- `def add_arguments(parser: argparse.ArgumentParser) -> None`
- `def run(ws: Path, args: argparse.Namespace, adapter) -> dict`  — returns `envelope.make(...)`, never prints; `adapter` is None when NEEDS_ADAPTER is False.

CLI (src/kx/cli.py):
- `class UsageError(Exception)`; `class KxParser(argparse.ArgumentParser)` whose `error()` raises UsageError (argparse must never print usage or exit 2).
- `discover_commands() -> dict[str, ModuleType]` — `pkgutil.iter_modules(kx.commands.__path__)`, import each, key = module.NAME, sorted by name.
- `dispatch(argv: list[str] | None, *, commands: dict | None = None, adapter_factory=None) -> dict` — returns an envelope, never prints.
- `main(argv: list[str] | None = None, *, commands: dict | None = None, adapter_factory=None) -> int` — fd guard, dispatch, write one JSON line on the saved fd, return exit_code.
- Default adapter factory (used only when the chosen module has NEEDS_ADAPTER True): `importlib.import_module("kx.kaggle_adapter").KaggleAdapter()`. 06-02 creates that class; its constructor must not import kaggle.
- Every subparser automatically gets `--workspace` (type=Path, default=current dir) and `-h/--help`.

FakeAdapter (tests/kx/conftest.py) — generic so later plans never edit conftest to add methods:
- `FakeAdapter(script: dict[str, list | object] | None = None, *, username: str = "fake-user", leak_stdout: bool = False)`
- Attribute access to a name present in `script` returns a callable that appends `(name, args, kwargs)` to `self.calls` and returns the next scripted item (the last item repeats once exhausted). An item that is an Exception instance is raised; a callable item is called with the same args. A name NOT in `script` raises AttributeError (so an unexpected Kaggle call fails the test loudly). `leak_stdout=True` makes every call `print("FAKE-ADAPTER-LEAK")` first (fd-guard proof).
- fixture `fake_adapter` returns the FakeAdapter class.
