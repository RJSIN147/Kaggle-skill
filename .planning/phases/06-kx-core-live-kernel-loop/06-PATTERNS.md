**KaggleObject → JSON** (copy verbatim from spike `sources/001-competition-profile-from-api/probe.py` 21-46):
```python
def plain(obj, depth=0):
    if depth > 6: return str(obj)
    if obj is None or isinstance(obj, (str, int, float, bool)): return obj
    if isinstance(obj, (list, tuple)): return [plain(x, depth + 1) for x in obj]
    if isinstance(obj, dict): return {k: plain(v, depth + 1) for k, v in obj.items()}
    if hasattr(obj, "isoformat"): return obj.isoformat()
    fields = getattr(obj, "_fields", None)
    if fields:
        out = {}
        for f in fields:
            name = getattr(f, "field_name", None) or getattr(f, "name", None)
            if not name: continue
            try: out[name] = plain(getattr(obj, name), depth + 1)
            except Exception as exc: out[name] = f"<err {type(exc).__name__}>"
        return out
    return str(obj)
```

## Shared Patterns

### S1. Fail-clear control-plane reads (never overwrite, never guess)
**Source:** `scripts/init_workspace.py` 133-154 (`write_control_json` raises `MalformedControlJSON`), `scripts/scaffold_experiment.py` 61-79 (`_read_control_json`), `scripts/check_credentials.py` 306-327 (`MalformedStateJSON`).
**Apply to:** every `cmd_*` that reads `control/config.json`, `state.json`, `profile.json`, `experiment.json`, `kernel_run.json`.
```python
try:
    current = json.loads(raw)
except json.JSONDecodeError as exc:
    raise MalformedControlJSON(path, exc) from exc     # bytes left intact; caller → invalid envelope naming path.name
```
Do all reads **before** any mutation (`scaffold_experiment.main` 177-184: "so a corrupt control JSON blocks with nothing written").

### S2. Atomic writes
**Source:** `scripts/rebuild_ledger.py` 76-84 (identical copy in `regen_strategy.py` 237-246).
**Apply to:** `ledger.jsonl`, `strategy.md`, `kernel_run.json` (new), `profile.json`, `submissions.jsonl`.
```python
def _atomic_write(path: Path, text: str) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(path.suffix + ".tmp")
    tmp.write_text(text)
    os.replace(tmp, path)
```
Put one copy in `workspace.py` and import it; `submissions_log` has its own at 456+, and that one can stay.

### S3. Explicit-path git staging (never `git add -A`)
**Source:** `scripts/record_experiment.py` 212-227 and `scripts/init_workspace.py` 412-422.
**Apply to:** `kx init` scaffold commit, `kx run` pre-push commit (`experiment.json`, `train.py`, `kernel-metadata.json`), `kx strategy` cycle commit.
```python
present = [rel for rel in rels if (ws / rel).exists()]
if present:
    subprocess.run(["git", "add", "--", *present], cwd=str(ws), capture_output=True, text=True, check=False)
```

### S4. No-echo / quarantine for anything Kaggle-sourced
**Source:** `scripts/kaggle_gateway.py` 83-110 (buffers captured, never printed; fixed timeout marker) + 250-264 (`dump_last_error`); `scripts/record_experiment.py` 99-118 (`scan_kernel_log` is pure `marker in text`, never echoes).
**Apply to:** the adapter, kernel pull (never log `f.url`), the recorder, envelope errors. Only framework-authored strings and **our own** slugs go into envelopes (RESEARCH push example: `"sources": bad` is safe because they are our slugs).

### S5. No stdout from library code (CORE-01)
**Source:** RESEARCH Pattern 1 (fd guard). v1 modules print human messages to stdout (e.g. `record_experiment.py` 485-493, `regen_strategy.py` 298-299, `init_workspace.set_execution_target` 535).
**Apply to:** every ported module. Replace stdout `print` with returned data. `print(..., file=sys.stderr)` warnings may stay (the fd guard covers fd 1 only). Every `subprocess.run` keeps `capture_output=True` (already true in all v1 git helpers).

### S6. Injected dependencies for determinism
**Source:** `scripts/poll_kernel.py` 132-141 (`now`, `sleep`, `rng`, `status_fn` injected; `cancel_fn` accepted only to prove it is never called) + the WR-01 lesson (`tests/test_submissions_log.py` 262-298).
**Apply to:** `KaggleAdapter` (passed to every `cmd_*`), clocks in `kernel.py`, the `requests` session in pull (or a thin adapter method the fake overrides).

### S7. repr()-literal rendering into executed code (CR-01)
**Source:** `scripts/scaffold_experiment.py` 259-274 + the `tests/test_scaffold_experiment.py` 137-164 test.
**Apply to:** `train.py.tmpl` rendering. The charset gates (`_SLUG_RE`, canonical-ref regex, `_USERNAME_RE`) are defense in depth, **not** the primary defense.

**Apply to:** 06-01, before any `tests/kx/test_<v1-basename>.py` exists. `--import-mode=importlib` in `addopts` + the `tests/` sys.path shim in `tests/conftest.py`. Without it, `tests/kx/test_credentials.py` collides with `tests/test_credentials.py` and the whole run errors at collection.
