## Phase Goal

**As a** Kaggle competitor, **I want to** go from an empty folder to a recorded experiment through one `kx` CLI that runs my idea on a Kaggle script kernel by default, **so that** the core loop (idea, kernel run, machine-checked score, verdict, ledger, strategy) works live on the v2 foundations.

**This slice:** the user closes a cycle with `kx strategy --reasoning-file …`: the ledger is rebuilt from the
experiment folders, the living strategy doc is regenerated from tooling-written facts plus the AI's reasoning, the
verdict must exist first, and the cycle is committed.

Output: `src/kx/{ledger,lb_gap,submissions_log,strategy}.py`, `src/kx/templates/VERDICT.md.tmpl`,
`src/kx/commands/strategy.py`, and ported tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI-authored reasoning file -> strategy.md | free text spliced into a tracked doc |
| experiments/*/meta.json -> ledger/strategy facts | the only source of numbers in the strategy |
| workspace -> git history | the cycle commit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-18 | Tampering (fabricated scores) | strategy._render | mitigate | every number comes from the rebuilt ledger (tooling-written meta.json); the reasoning file is spliced verbatim and never parsed for numbers (v1 D-05/D-12 unchanged) |
| T-06-19 | Repudiation | skipped verdicts | mitigate | verdict gate: `kx strategy` refuses while VERDICT.md holds template sentinel lines derived from the template file |
| T-06-20 | Information disclosure | cycle commit | mitigate | stage_and_commit with explicit existing paths only (never `add -A`); leak_scan hook runs; a blocked commit returns `commit_blocked` without echoing hook output |
| T-06-21 | Tampering | ledger rebuild | mitigate | validate_meta before a row is emitted; invalid meta warns on stderr and is skipped (v1 behaviour); atomic writes |
| T-06-22 | Information disclosure | reasoning file path outside the workspace | accept | the file is only read and copied into strategy.md; it is committed only when it lives inside the workspace |
</threat_model>
