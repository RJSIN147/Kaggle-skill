**Four bugs from the live EXP-05 kernel run are fixed. convert_notebook now writes a python3 kernelspec, so papermill can run the notebook. ## What changed

- **BUG 1 (convert_notebook.py):** the jupytext argv now carries `--update-metadata` followed by `json.dumps(_NOTEBOOK_METADATA)`, a single argv element with kernelspec python3 / "Python 3" / python and language_info python. After a zero exit, the notebook is re-read. If it is unreadable or has no `metadata.kernelspec.name`, convert returns 1 and prints a stderr message that mentions "kernelspec".
- **BUG 2:** added a new `parse_args(argv=None)` that uses `parse_known_args`.
- **BUG 3:** `_finish(rc)` raises SystemExit only when `ipykernel` is not in `sys.modules`. The tail is now `_finish(main())`.
- **BUG 4:** added `KAGGLE_WORKING` / `on_kaggle_kernel()` / `resolve_exp_dir()`. When `/kaggle/working` exists, `args.exp_dir` is set to that directory, so result.json, artifacts/oof.npy and submission.csv are written flat.
- **resolve_data_dir:** checks `/kaggle/input/<slug>` first, then `/kaggle/input/competitions/<slug>`. If `__file__` is present it falls back to `<ws>/data`. With neither, it raises FileNotFoundError naming both Kaggle paths. `main()` prints `data_dir: <path>`.
- **Guard:** added `benign_warnings.json`, a JSON-array log copied from the live run (pydevd, sklearn UserWarning, mistune SyntaxWarning, `[NbConvertApp]`). It scans clean and records SUCCESS. The same log with a papermill traceback appended still scans as a failure.
- **Docs:** added a Phase 4 live section to the reference doc. Script comments now say A2/A4 are verified live and A3 is confirmed. 04-05-SUMMARY has a Resolution subsection. STATE.md is updated (EXP-05 deferred row, Phase 4 blocker marked resolved, quick-task row, last activity) but not committed; the orchestrator will commit it.
