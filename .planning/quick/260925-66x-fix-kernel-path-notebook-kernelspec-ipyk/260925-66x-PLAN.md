   `sys.argv` (`-f <connection-file.json>`), argparse exits, papermill reports `SystemExit: 2`.

   (including 0) as an error output; papermill treats it as an execution error.

   outputs land in `/kaggle/working/experiments/exp-NNN/...`, but `pull_kernel.py` runs
   `kernels output -p <exp_dir>` and expects them FLAT. Silent contract break.

`cv_mean 0.8305002824681439` with fold scores identical to the local run
(`[0.8547486, 0.8258427, 0.80898876, 0.8258427, 0.83707865]`): local/kernel parity.
